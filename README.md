# Fynlo — Smart Business Software

AI-powered accounting and business management software built with Electron, React, and Firebase.

## 🌐 Live Demo
👉 [https://lakshyaloungani09.github.io/fynlo/](https://lakshyaloungani09.github.io/fynlo/)

## ✨ Features
- Billing & GST invoicing with PDF export
- Inventory management with low stock alerts
- Party ledger with bill tracking & payments
- Real-time cloud sync via Firebase
- Voice AI entry in Hindi/English
- Financial reports — P&L, Trial Balance

## 🛠 Tech Stack
React.js • Electron • Firebase • JavaScript • Vite
